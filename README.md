## `03 // PROJECTS`

### ☕ Hi & Hello — Bakery • Café

Projeto acadêmico desenvolvido em dupla para simular a criação de um site de apresentação de uma cafeteria fictícia.

O projeto foi uma oportunidade de aplicar conhecimentos de desenvolvimento web, trabalhar em equipe e compreender melhor o processo de construção de uma interface.

**Minha contribuição:**
- Estruturação das páginas utilizando HTML.
- Personalização visual e organização do layout com CSS.
- Desenvolvimento de interações básicas com JavaScript.
- Prática de integração entre HTML, CSS e JavaScript.
- Colaboração com um colega durante o desenvolvimento.
- Utilização de Git e GitHub no contexto do projeto.
- Apresentação em sala de aula, explicando as tecnologias e as decisões tomadas.

**Tecnologias:** HTML, CSS, JavaScript e Firebase.
